# Desktop Sorter — сортировка рабочего стола Windows

Маленькая программа (~2 МБ, один `.exe`, без установки), которая раскладывает ярлыки и файлы с рабочего стола по папкам-категориям: **Игры, Браузеры, Мессенджеры, Офис, Разработка, Графика и монтаж, Утилиты, Документы, Изображения, Видео, Музыка, Архивы, Установщики** и т.д.

## Скачать

Готовые файлы — на странице [Releases](../../releases/latest) или в папке [`dist/`](dist):

| Файл | Для чего |
|---|---|
| `DesktopSorter.exe` | 64-битная Windows (большинство компьютеров) |
| `DesktopSorter-32bit.exe` | 32-битная Windows (старые ноутбуки) |

Поддерживаются **Windows 7, 8, 8.1, 10, 11**.

## Как пользоваться

1. Скачайте `DesktopSorter.exe` (можно положить прямо на рабочий стол — себя программа не переносит).
2. Запустите и выберите пункт меню:
   - `1` — отсортировать (сначала покажет список и спросит подтверждение);
   - `2` — предпросмотр, ничего не перемещает;
   - `3` — отменить последнюю сортировку (всё вернётся на свои места);
   - `0` — выход.

Параметры командной строки (например, для автозапуска):

```
DesktopSorter.exe -preview   показать, что куда будет перемещено
DesktopSorter.exe -auto      отсортировать без вопросов
DesktopSorter.exe -undo      отменить последнюю сортировку
```

## Безопасность

- Работает **только с папкой рабочего стола текущего пользователя** (определяется через системный API, поэтому учитывается перенос рабочего стола в OneDrive или на другой диск).
- Перемещает **только файлы, лежащие прямо на рабочем столе**. Папки пользователя, скрытые и системные файлы (`desktop.ini` и т.п.) не трогаются.
- Программы, на которые указывают ярлыки (на `C:\`, `D:\` и т.д.), **не изменяются** — ярлык лишь открывается на чтение, чтобы узнать, куда он ведёт.
- Перемещение делается переименованием внутри рабочего стола: содержимое файлов не копируется и не меняется.
- Если имя занято — файл получит имя `файл (2).ext`, ничего не перезаписывается.
- Не нужны права администратора, нет доступа к интернету, нет записей в реестр, нет фоновых процессов.
- Журнал отмены хранится в скрытом файле `.desktop-sorter-undo.json` на рабочем столе. При отмене удаляются только созданные программой **пустые** папки.

## Оптимизация для слабых ПК

- Написано на Go, один статический `.exe` без .NET / Python / Visual C++ Runtime.
- Потребление памяти — несколько мегабайт, работа занимает доли секунды.
- Один проход по рабочему столу, из каждого ярлыка читается не больше 64 КБ; тяжёлый COM/Shell API не используется.
- Есть 32-битная сборка для старых ноутбуков.

## Как определяется категория

- **Ярлыки (`.lnk`)** — по имени ярлыка и пути программы (например, `...\steamapps\...` → Игры, `chrome.exe` → Браузеры). Неизвестные → «Программы».
- **Интернет-ярлыки (`.url`)** — `steam://rungameid/...` и аналоги → Игры, остальное → «Ссылки на сайты».
- **Файлы** — по расширению (`.docx` → Документы, `.jpg` → Изображения, `.zip` → Архивы, `setup.exe`/`.msi` → Установщики…). Неизвестные → «Прочее».

Списки ключевых слов находятся в [`rules.go`](rules.go) — их легко дополнить.

## Сборка из исходников

Нужен [Go](https://go.dev/dl/) 1.20 (последняя версия с поддержкой Windows 7; на новых Go тоже собирается, но только для Windows 10+).

```
build.bat        # на Windows
./build.sh       # на Linux/macOS
go test ./...    # тесты
```
